SITIO WEB SyRA — INSTRUCCIONES DE PUBLICACIÓN GRATUITA

ARCHIVOS INCLUIDOS
- index.html
- styles.css
- script.js
- robots.txt
- sitemap.xml

ANTES DE PUBLICAR
1. Reemplazar en index.html, robots.txt y sitemap.xml:
   TU-USUARIO por el nombre real de usuario de GitHub.
2. Confirmar que la marca correcta sea “SyRA”.
3. Revisar dirección, matrícula, teléfono y correo.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crear una cuenta en github.com.
2. Crear un repositorio público llamado: syra
3. Subir los cinco archivos.
4. Entrar en Settings > Pages.
5. En “Build and deployment”, elegir “Deploy from a branch”.
6. Elegir rama “main” y carpeta “/(root)”. Guardar.
7. El sitio quedará en: https://TU-USUARIO.github.io/syra/

PARA APARECER EN GOOGLE
1. Crear o reclamar el Perfil de Empresa de Google con el nombre SyRA.
2. Ingresar el sitio publicado, teléfono, zona de servicio, horarios y fotos propias.
3. Entrar en Google Search Console.
4. Añadir la dirección del sitio.
5. Enviar sitemap.xml.
6. Usar “Inspección de URLs” para solicitar indexación de la página principal.

IMPORTANTE
Publicar la web no garantiza aparecer inmediatamente ni en los primeros puestos. La visibilidad mejora al completar y verificar el Perfil de Empresa, mantener datos coherentes y sumar contenido, fotos y reseñas reales.
